# Grand Piano samples

These files are a bandwidth-conscious subset of **Salamander Grand Piano**,
recorded by Alexander Holm from a Yamaha C5. The original library is licensed
under [Creative Commons Attribution 3.0 Unported](https://creativecommons.org/licenses/by/3.0/).

- Original source: https://archive.org/details/SalamanderGrandPianoV3
- Maintained SFZ edition and license: https://github.com/sfzinstruments/SalamanderGrandPiano
- Web-optimized MP3 distribution used here: https://tonejs.github.io/audio/salamander/

The application keeps one velocity layer and sixteen roots locally. Neighboring
notes are pitch-shifted by no more than three semitones. This avoids a network
dependency during playback while keeping the educational viewer lightweight.
