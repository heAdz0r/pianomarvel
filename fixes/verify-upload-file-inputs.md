# Проверка файлов перед отправкой формы

## Проблема

На форме Piano Marvel метаданные уже были видны, а файловые поля ещё оставались
пустыми. Это выглядело так, будто локальный инструмент не передал найденные
файлы.

## Проверка

Dry-run в реальной авторизованной форме подтвердил актуальные селекторы и
успешное назначение всех пяти категорий через `setInputFiles`. Причиной
визуального несоответствия был порядок: метаданные заполнялись раньше файлов.

## Решение

`server/piano.ts` теперь:

1. назначает все файлы до заполнения текстовых полей;
2. читает `input.files` после каждого назначения;
3. сравнивает фактические имена с ожидаемыми;
4. не нажимает Save и возвращает точную ошибку, если файл не прикрепился.

Интеграционный тест проверяет MIDI, MXL, аудио, PDF и обложку в реальном Chrome.
